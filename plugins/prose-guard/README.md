# prose-guard

Quality control for written output.

## Skills

| Skill | What it does |
|-------|--------------|
| `review-technical-claims` | Audit a document for unverified claims, verify attributions against real sources (SIFT), fix errors, and give an honest critical review. Call it directly with `/prose-guard:review-technical-claims [document]` or just ask. |

## Agents

- `tone-checker` — flag AI-slop markers (filler words, em-dashes, sandwich structure) in agent-generated text and suggest rewrites
